# Overview Sistem CMS & Jadwal Training Admin Branch

## Ringkasan

Pengantar guideline sistem CMS untuk Admin Branch Timedoor Academy: struktur 6 chapter materi, jadwal training 4 hari, tata letak antarmuka CMS, dan urutan wajib saat melakukan persiapan awal cabang.

---

## Struktur materi guideline

Guideline Admin Branch terbagi menjadi 6 chapter:

| Chapter | Judul | Isi utama |
| --- | --- | --- |
| 1 | Preparation | Create Teachers, Create Room, Create Class, Create Events/Trials |
| 2 | Register Student | Input Inquiry, Register Customer + Assign Trial, Student Detail, Parent Information, Student Session, Manage Coins, Referral Reward |
| 3 | Order Product | Product & Pricing, Create Session, Send Payment Link, Paid Invoice Manually, Pending Product & Redeem, Generate Schedule, Check Attendance |
| 4 | Session Management | Session Information, Session Settings, Learning and Session Status, Book History, Schedule Setting, Invoice History, Pending Product, Session Study Case |
| 5 | Accounting Management | Upcoming Contract, Combine Invoice, Paylater, Discount, Approve Attend, Approve Report |
| 6 | FAQ | Penjelasan FAQ |

## Jadwal training 4 hari

| Hari | Materi |
| --- | --- |
| DAY 1 | Create Teachers (Ch1), Create Room (Ch1), Create Class (Ch1), Create Trials (Ch1), Input Inquiry (Ch2) |
| DAY 2 | Register Customer + Assign Trial (Ch2), Detail Customer (Ch2), Manage Coin Student (Ch2), Create Session (Ch3), Paid Invoice (Ch3) |
| DAY 3 | Generate Schedule (Ch3), Check Schedule Attendance (Ch3), Session Management (Ch4), Accounting Management (Ch5) |
| DAY 4 | FAQ explain (Ch6) |

## Tata letak antarmuka CMS

- **Sidebar** — untuk mengakses menu-menu lain.
- **Branch Option** — tempat mengakses cabang.
- **Country, Light/Dark mode, dan Profile** — untuk mengakses negara, mode terang/gelap, dan profil.
- **Dashboard** — tempat penyajian data analisis mengenai inquiry, invoice, monitoring cabang, dan lain-lain.

## Urutan wajib saat Preparation

Admin dapat memulai dari Teachers atau Rooms, tetapi **keduanya harus dibuat terlebih dahulu** sebelum ke tahap selanjutnya, karena pembuatan Class dan Trials membutuhkan Teacher dan Room.

Urutan yang benar:

1. Create Teachers dan Create Room (bebas mana dulu, tapi harus keduanya)
2. Create Class
3. Create Events/Trials
