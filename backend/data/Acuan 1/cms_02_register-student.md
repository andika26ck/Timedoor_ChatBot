## 2.2 Register Customer + Assign Trial
**Tujuan:** Mendaftarkan customer dari inquiry menjadi student resmi.
**Langkah:**
1. Klik menu **Customer** → **Inquiry**
2. Cari inquiry yang akan di-register, klik **Action Button**
3. Isi data di halaman **Parent Information** (nama, kontak, dll)
4. Jika parent sudah pernah terdaftar sebelumnya, cari nama parent di kolom Parents Name menggunakan nama atau nomor telepon — data akan otomatis terisi
5. Isi data **Student Information**
6. Jika ada lebih dari 1 anak (siblings), klik **Add Children**
7. Klik **Continue**
8. **Assign Trial** ke student (opsional — bisa di-skip jika tidak ada trial)
9. Klik **Save & Finish**
> Student yang sudah terdaftar dapat dilihat di **Student List**.
---
## 2.3 Student Detail
**Tujuan:** Melihat dan mengelola informasi detail student.
**Akses:** Menu **Customer** → **Student** → **Action Button**
**Yang bisa dilakukan di halaman ini:**
- **Edit Student Info** — ubah informasi siswa
- **Non-Active Student** — gunakan jika siswa sudah drop/berhenti les
- **Set as Password** — reset password akun siswa
---
## 2.4 Parent Information
**Akses:** Melalui halaman Student Detail
Admin dapat melihat dan mengedit informasi orang tua secara detail dari halaman ini.
---
## 2.5 Student Session (Check Trial)
**Akses:** Halaman Parent Information → tab Student Session
Halaman ini menampilkan seluruh session (paket) yang pernah dibeli oleh siswa, termasuk trial. Setiap session memiliki 2 tombol action:
- **Book History** — riwayat buku dan learning progress
- **Session Information** — detail informasi session aktif
---
## 2.6 Manage Coins
**Akses:** Halaman Parent Information → tab Coins
Admin dapat melihat jumlah koin yang dimiliki siswa. Koin diperoleh melalui kehadiran, Quiz, dan Exam. Admin juga dapat menambah atau mengurangi koin secara manual.
---
## 2.7 Referral Reward
**Akses:** Halaman Parent Information → tab Referral
Admin dapat mengecek apakah Referral Discount seorang siswa sudah digunakan, dan apakah siswa tersebut mendapatkan Referral Discount sebagai benefit.
**Cara Klaim Referral sebagai Cashback:**
1. Klik **Claim** pada referral discount yang tersedia
2. Isi kolom yang diperlukan
3. Klik **Confirm**
4. Admin bertugas mengirimkan cashback kepada orang tua setelah diklaim
