## Teacher - Check Class List

### Ringkasan
Halaman Class List menampilkan kelas-kelas yang di-assign ke akun teacher. Kelas milik teacher lain tidak akan muncul di Class List.

---

Halaman Class List menampilkan kelas-kelas yang di-assign ke akun teacher. Kelas milik teacher lain tidak akan muncul di Class List.
> Pastikan memilih tipe Class sesuai ketentuan masing-masing cabang.
Teacher dapat melihat informasi kelas seperti peserta kelas (teacher dan student) melalui tab **Participants**, dan jadwal kelas melalui tab **Attendance**.
> Klik tombol Detail untuk melihat isi kelas.
