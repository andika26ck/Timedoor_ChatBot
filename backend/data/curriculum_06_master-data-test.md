# Curriculum Maker - Master Data Test

## Ringkasan
Test adalah kumpulan soal yang bisa dirujuk oleh Material atau Sub Material bertipe Test. Satu Test bisa digunakan di banyak Material berbeda.

---

Test adalah kumpulan soal yang bisa dirujuk oleh Material atau Sub Material bertipe Test. Satu Test bisa digunakan di banyak Material berbeda.
Test dikelola melalui menu **Test** di sidebar.
## Membuat Test
Saat membuat Test, isi:
| Field | Keterangan |
| --- | --- |
| Subject | Subject yang sesuai |
| Course | Course yang sesuai |
| Nama Test | Nama Test |
| Durasi | Durasi pengerjaan Test |
| Type | Tipe Test (lihat tabel di bawah) |
