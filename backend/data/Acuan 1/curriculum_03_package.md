# Curriculum Maker - Package

## Ringkasan
Package adalah produk yang dijual ke customer. Setiap Package berisi 1 Course dan merupakan satu-satunya yang masuk ke Product di sistem.

---

Package adalah produk yang dijual ke customer. Setiap Package berisi 1 Course dan merupakan satu-satunya yang masuk ke Product di sistem.
Curriculum Maker bertugas membuat struktur Package. Harga Package di-set per branch oleh Admin branch masing-masing.
## Membuat Package
Saat membuat Package, isi:
<table header-row="true">
<tr>
<td>Field</td>
<td>Keterangan</td>
</tr>
<tr>
<td>Nama Package</td>
<td>Nama Package yang akan ditampilkan</td>
</tr>
<tr>
<td>Course</td>
<td>Course yang menjadi isi Package ini. 1 Package hanya bisa memilih 1 Course</td>
</tr>
<tr>
<td>Bahasa</td>
<td>Bahasa yang digunakan pada Package ini</td>
</tr>
<tr>
<td>Durasi</td>
<td>Durasi dalam menit</td>
</tr>
</table>
> Harga Package tidak diatur di sini — harga di-set per branch oleh Admin branch masing-masing dan bisa berbeda antar branch.
