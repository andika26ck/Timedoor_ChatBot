## Curriculum Maker - Learning Path

### Ringkasan
Learning Path adalah jalur belajar yang berisi rangkaian Course secara berurutan.

---

Learning Path adalah jalur belajar yang berisi rangkaian Course secara berurutan.
Learning Path dikelola melalui menu **Learning Path** di sidebar.
### Membuat Learning Path
Saat membuat Learning Path, isi:
- **Nama Learning Path**
- **Urutan Course** — tambahkan Course-Course yang menjadi bagian dari jalur belajar ini, lalu susun urutannya
> 1 Course bisa masuk ke banyak Learning Path yang berbeda.
Tidak ada field tambahan lain selain nama dan susunan Course.
